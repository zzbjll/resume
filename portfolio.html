案例 01

AI 员工(智能体)平台

自研 · 2026 · 三岗位 100 单实测

内核提供「怎么干活」的通用机制——工具注册、闸门、幂等、预算、审计轨迹;业务判定全部由插件提供。三个完全不同的岗位(贷款 / 对账 / 风控)跑在同一内核上,后两个岗位交付时内核一行没改(有 git 记录)。

岗位插件
贷款 · 对账 · 风控,即插即用;内核零改动
→
agentcore 内核
注册 · 预算 · 幂等 · 轨迹
→
闸门(判定权)
资金 / 风控动作不过闸不执行,handler 一次都不会被调用
→
工具执行
异常转成结果交回插件,不炸任务
→
审计轨迹
append-only + 哈希链,改一条即被发现
◆蓝框 = 判定点:模型只写给人看的说明,判定全是确定性规则◆岗位二 / 三交付 agentcore 零 diff(git 可查)

01内核边界

内核不 import 任何插件,有测试把「平台边界」变成可执行断言;换领域需要动内核 = 契约错了,不是加分支。

02判定权在闸门

工具用声明表达门禁(money / risk_policy);内核在调用前问闸,测试断言不过闸时 handler 一次都没被调用。

03幂等与审计

平台级幂等:同任务 + 工具 + 参数只执行一次(实测拦 29 次重复回调);轨迹只存摘要,哈希链可校验未改动。

可核证据:内核 + 三插件共 2939 行 · 67 个测试全绿 · 三岗位各 100 单、整批重放 100/100 一致 · 16 工具 / 4 闸门同内核联跑 0 中止 · 轨迹哈希链 622 条校验通过

01档位路由

链式换家防「同账号互切」;发布闸滚动替换 + 5xx 比例闸,「容器 healthy ≠ 可用」,等到流量路径真 200。

可核证据:30.1s → 3.6s 端到端 · 约 120ms 同步阻塞定位 · −60% 单会话成本 · 5 厂商 / 12 模型 / 9 客户端 · 用量队列 2000 有界

案例 03

长时记忆与召回

重庆智识维度 · 主导 · 运行中

记忆以事件溯源方式存储(纯追加 + 投影,任何时点可重建);召回用词法 + 向量双路、RRF 融合,融合后再过两道门。两件反直觉的事:重排器实测负贡献当场关停;旧评测集自查出泄漏,作废重建后再验。

会话回合

→
事件溯源写入
append-only SSOT + 投影;抽取只产草稿,升版权归人
→
双臂召回
词法臂 ∥ 向量臂,各自召回
→
RRF 融合 c=60
只比秩不比分;0.7 相对分门 + 强命中保护
→
注入
预算内摘要进上下文
◆强命中保护:修「单臂 top1 被相对分门误杀」——相对分门会系统性砍掉单臂独占的对口记忆◆记忆读侧一律带 revision / content_hash,过期可查

01事件溯源

纯追加 SSOT + 投影,revision 乐观并发;任何时点可从事件全量重放重建记忆状态。

02双臂 + 两道门

RRF 只用秩、不用分数(两臂量纲不可比);0.7 相对分门守住相关度,强命中保护防误杀。

03用数据否掉自己

CE 重排同口径 A/B 实测负贡献(R@4 0.797 → 0.707)当场关停;旧评测集别名泄漏自查作废、去泄漏重建后再验。

可核证据:P@1 0.853 → 0.907(64/75 → 68/75,同口径 A/B)· 去泄漏评测 R@10 0.870 → 0.911(n=728)· CE 重排负贡献即下架 · RRF c=60

案例 04

金融导流平台

重庆智识维度 · 技术负责人 · 生产运行

贷超导流生产系统全链路:上游流量 → 撞库去重 → 前筛路由 → 下游资方授信 / 放款 → 日终对账。一次生产撞库雪崩的根治:根因是缺索引叠加超时重试的正反馈——越慢越重试、越重试越慢。

→

→

→

幂等净补差;余额唯一权威 = 台账 SUM
◆适配器 SPI:新渠道 = 一条配置 + 一个实现类,核心域零改动◆一致性:四类 Outbox(事务内 PENDING / 重投 / 死信)+ 终态 CAS 单点落定 + Redis INCR 原子占额

01雪崩根治

6.6s → 264ms(生产同窗口 A/B);峰值在途 72.9 → 3.24,是并发堆积被削平,不是单点变快。

02架构收敛

核心域只认 13 类 Canonical 模型,渠道与资方差异收敛到适配器 SPI 与注册表,新渠道核心零改动。

03并发一致性

双实例日限额用 Redis INCR 原子预占;终态 DB CAS 只允许一次落定;进件唯一键 + REQUIRES_NEW 防重复。

可核证据:撞库 6.6s → 264ms(生产同窗口 A/B)· 峰值在途 72.9 → 3.24 · 进件超时 29.5s → 2.5s · 13 类 Canonical + 适配器 SPI
